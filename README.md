# ☕ Core Java Learning Repository

A structured collection of Java programs, coding exercises, and practical examples created while learning and practicing Core Java concepts. This repository documents my learning journey, strengthens my programming fundamentals, and provides hands-on practice with Java's core features.

## 📚 Topics Covered

### 1. Core Java Fundamentals
- Variables, data types, and operators
- Conditional statements and loops
- Methods and variable arguments
- Arrays and problem-solving
- Static and non-static members
- Type casting and variable scope.

### 2. Object-Oriented Programming (OOP)
- Classes and objects
- Inheritance and polymorphism
- Abstraction and abstract classes
- Encapsulation
- Method overloading and overriding
- Upcasting and runtime polymorphism

### 3. String Handling
- String class and string manipulation
- StringBuffer and mutable strings
- String reversal and character operations
- String-related practice problems

### 4. Collections Framework
- List: ArrayList, LinkedList, Vector, and Stack
- Set: HashSet, LinkedHashSet, and TreeSet
- Map: HashMap, LinkedHashMap, TreeMap, Hashtable, and WeakHashMap
- Iterator, ListIterator, and Enumeration
- Comparable and Comparator
- Sorting and custom comparison logic

### 5. Exception Handling
- Exception handling fundamentals
- Try-catch and exception propagation
- Custom exceptions
- Runtime exceptions and error handling

### 6. Multithreading
- Thread class and Runnable interface
- Creating and executing threads
- Thread-based practical examples
- Concurrent execution fundamentals

### 7. Input/Output (I/O) and Serialization
- FileInputStream and FileOutputStream
- Byte and character stream concepts
- ObjectInputStream and ObjectOutputStream
- File handling and properties files
- Serialization and deserialization

### 8. Arrays and Problem Solving
- Finding maximum elements
- Searching for target elements
- Calculating averages
- Basic mathematical and logical problems

### 9. Java Language Features
- Modern Java features and version exploration
- Java 25 feature experiments
- Practical examples of Java syntax and APIs
